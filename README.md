# Gerador de Propostas - R.L Serviços Elétricos

Aplicação estática para preencher propostas comerciais e gerar PDFs com o papel timbrado da empresa.

## Características

- Funciona inteiramente no navegador
- Não utiliza banco de dados
- Não armazena os dados preenchidos
- Razão social e CNPJ fixos
- Geração e visualização de PDF
- Dois campos de assinatura independentes
- Data posicionada abaixo das assinaturas
- Compatível com GitHub Pages

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta, mantendo a pasta assets.
3. Abra Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Selecione a branch main e a pasta / (root).
6. Clique em Save.

Após a publicação, o GitHub exibirá o endereço do gerador.

## Privacidade

Os dados são processados localmente pelo navegador. Nenhuma proposta é enviada para servidor ou banco de dados.
